2. OBJETIVO GENERAL
======================================================================

Analizar mediciones de contaminantes, respuestas de sensores y condiciones
ambientales para identificar patrones y estimar la concentración de CO.

La variable principal que se intenta predecir es CO(GT), que representa la
concentración de monóxido de carbono medida por un analizador de referencia.

======================================================================
3. DATASET Y VARIABLES
======================================================================

El dataset Air Quality contiene mediciones horarias de una estación de
monitoreo ambiental.

Las variables principales son:

Date:
Fecha en que se realizó la medición.

Time:
Hora de la medición.

CO(GT):
Concentración de monóxido de carbono. Es la variable objetivo principal
para la regresión.

PT08.S1(CO):
Respuesta del sensor relacionado con CO.

NMHC(GT):
Concentración de hidrocarburos no metánicos.

C6H6(GT):
Concentración de benceno.

PT08.S2(NMHC):
Respuesta del sensor relacionado con NMHC.

NOx(GT):
Concentración de óxidos de nitrógeno.

PT08.S3(NOx):
Respuesta del sensor relacionado con NOx.

NO2(GT):
Concentración de dióxido de nitrógeno.

PT08.S4(NO2):
Respuesta del sensor relacionado con NO2.

PT08.S5(O3):
Respuesta del sensor relacionado con ozono.

T:
Temperatura en grados Celsius.

RH:
Humedad relativa en porcentaje.

AH:
Humedad absoluta.

6. QUÉ SIGNIFICA -200
======================================================================

En el dataset de UCI, -200 es un marcador de dato faltante.

No significa que exista una concentración negativa de CO ni una temperatura
de -200 grados. Es una forma especial de indicar que no hubo una medición
válida o disponible.

En la exploración se conservaron los -200 para poder contarlos y explicar
el problema. En la copia procesada se transformaron a valores faltantes.
El archivo original nunca se modificó.

======================================================================
7. VALORES ATÍPICOS
======================================================================

Un valor atípico es una observación que se aleja mucho del comportamiento
normal de los demás datos.

Se utilizaron gráficas de cajas y bigotes para detectarlos.

Un valor atípico no se elimina automáticamente porque puede representar:

- Un episodio real de contaminación.
- Una situación ambiental poco común.
- Una lectura extraña de un sensor.
- Un error de captura.

Por eso primero se diagnostica y después se decide qué tratamiento aplicar.

9. BANDA_CO
======================================================================

El archivo original no trae una etiqueta de calidad del aire llamada banda.
Para aplicar clasificación se creó una variable académica:

organizar el problema de clasificación dentro del proyecto.

11. REGRESIÓN
======================================================================

El notebook de modelos es:

notebooks/PotencianoMendez_JoseGamaliel_U3_Modelos.ipynb

La regresión se usa cuando se quiere predecir un número.

En este proyecto se predice CO(GT).

Variables de entrada principales:

- PT08.S1(CO)
- PT08.S2(NMHC)
- PT08.S3(NOx)
- PT08.S4(NO2)
- PT08.S5(O3)
- T
- RH
- AH

Se utilizó una separación temporal aproximada de 80 % para entrenamiento
y 20 % para evaluación.

Resultados de regresión lineal:

- MAE: 0.344.
- RMSE: 0.484.
- R2: 0.862.

MAE significa error absoluto medio. Indica cuánto se equivoca el modelo en
promedio.

RMSE también mide el error, pero castiga más los errores grandes.

R2 indica qué proporción de la variación explica el modelo. Un R2 de 0.862
indica que el modelo explica aproximadamente el 86.2 % de la variación del
conjunto de evaluación.

Estos resultados son preliminares y solo aplican al dataset analizado.

======================================================================
12. CLASIFICACIÓN
======================================================================

La clasificación se utiliza cuando la respuesta es una categoría.

En este proyecto las categorías son:

- Baja.
- Media.
- Alta.

Se utilizó regresión logística para clasificar las bandas.

Resultados:

- Accuracy: 0.865.
- Macro-F1: 0.849.

Accuracy es la proporción general de predicciones correctas.

Macro-F1 calcula el desempeño de cada clase y obtiene un promedio. Es útil
porque las tres bandas no tienen exactamente la misma cantidad de datos.

La matriz de confusión permite saber qué bandas se clasificaron bien y
cuáles se confundieron entre sí.

======================================================================
13. CLUSTERING
======================================================================

Clustering es un método no supervisado.

No se le proporciona una respuesta correcta al algoritmo. El algoritmo
busca grupos de registros que tengan características parecidas.

En este proyecto se formaron tres grupos utilizando variables de sensores
y ambiente.

El coeficiente de silueta fue 0.265.

Este valor muestra que los grupos son exploratorios y no están totalmente
separados. No deben interpretarse como categorías oficiales de calidad del
aire.

======================================================================
14. PCA
======================================================================

PCA significa Análisis de Componentes Principales.

Sirve para resumir muchas variables en menos dimensiones. En este proyecto
se redujeron las variables a dos componentes principales.

Los dos componentes explicaron aproximadamente 77.5 % de la variación.

Esto permite observar patrones de forma más sencilla en una gráfica.

17. RESPUESTAS CORTAS PARA EL PROFESOR
======================================================================

¿Por qué elegiste CO(GT)?

Porque es una medición numérica de referencia y permite estudiar si las
respuestas de sensores y las condiciones ambientales ayudan a estimarlo.

¿Qué significa -200?

Es el marcador de dato faltante definido por UCI. No es una medición real.

¿Modificaste el archivo original?

No. El original está en data/raw/ y las transformaciones se hicieron en
copias dentro de data/processed/.

¿Qué diferencia hay entre regresión y clasificación?

La regresión predice un número. La clasificación predice una categoría.

¿Qué es un modelo supervisado?

Es un modelo que aprende usando datos de entrada y una respuesta conocida.

¿Qué es un modelo no supervisado?

Es un modelo que busca patrones o grupos sin tener una respuesta conocida.

¿Qué hace el ETL?

Lee los datos, los transforma en una copia de trabajo y guarda una salida
organizada para las siguientes etapas.

¿Qué es el Data Mart?

Es una base organizada para consultar el tema específico de calidad del
aire.

¿Qué contiene el dashboard?

Contiene indicadores de CO y NO2, bandas de CO, relación entre CO y un
sensor, y filtros por tiempo y categoría.

¿Los resultados son definitivos?

No. Son resultados preliminares y dependen de la calidad y limitaciones
del dataset.

18. EXPLICACIÓN COMPLETA PARA DECIR EN LA REVISIÓN
======================================================================

Mi proyecto analiza la calidad del aire utilizando el dataset Air Quality
de UCI. Primero conservé el archivo original y lo exploré con Pandas y
Jupyter. Revisé la estructura, las columnas, los tipos de datos, los
valores faltantes y los posibles valores atípicos. Detecté que el valor
-200 representa un dato faltante.

Después creé una copia procesada mediante un proceso ETL. En esa copia
combiné la fecha y la hora, generé variables de tiempo, ordené los
registros y creé bandas académicas de concentración de CO. Posteriormente
construí un Data Mart con una dimensión de tiempo, una dimensión de
sensores y una tabla de hechos.

Con los datos procesados ejecuté una regresión lineal para estimar CO(GT),
una clasificación logística para separar las bandas baja, media y alta,
clustering para identificar grupos y PCA para resumir variables.

Finalmente utilicé Power BI para crear un dashboard con promedios de CO y
NO2, distribución de bandas, relación entre CO y el sensor PT08.S1(CO), y
filtros de año, mes y banda.

Todo el proyecto está documentado en GitHub. El archivo original se
conservó sin modificaciones y los resultados se guardaron en archivos
derivados separados.
